# Despliegue en GitHub y Streamlit Cloud

1. Descomprima el ZIP.
2. Suba el **contenido interno** a la raíz del repositorio.
3. Confirme que `app.py`, `config.py` y `requirements.txt` estén en la raíz.
4. Conserve las carpetas `.streamlit`, `core`, `dashboard`, `maps`, `simulator`, `ai`, `reports`, `tests` y `data`.
5. En Streamlit Cloud seleccione `app.py` como Main file path.
6. Ejecute **Reboot app** después del commit.

No mezcle archivos de V3, V4 y V5. Cargue este paquete completo como una única versión.
